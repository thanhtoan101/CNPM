# AI-powered Film Photography Platform
AI-powered platform connecting film photography enthusiasts Film Processing Labs.
Nền tảng kết nối cộng đồng nhiếp ảnh và các Film Lab (Minilab) Tích hợp AI.
## Project Objectives
The project aims to build a digital ecosystem photographers, Film Labs, photography
## Main Products
- Mobile application for photographers
- Web portal for Film Lab owners
- Web administration system
- Marketplace for photography equiment
- Community and knowledge-sharing platform
- Digital Film Archive
- AI Recommendation Engine
- AI-powered Photography Assistant
- Backend services and cloud infrastructure
