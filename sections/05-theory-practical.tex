\section*{3.2.e Theory and Practical}
\addcontentsline{toc}{section}{3.2.e Theory and Practical}

The proposed platform combines software engineering principles, cloud
computing, database management, artificial intelligence, search technologies,
and mobile and web development. This section describes the theoretical
foundations and the practical technologies proposed for implementing the
system.

\subsection{Software Engineering Architecture}

The platform follows a modular and service-oriented approach in which major
system components are separated according to their responsibilities.

The main components include the Mobile Application, Web Portal, Backend
Services, AI Services, Database, Search Engine, and Cloud Storage. This
separation improves maintainability because each component can be developed,
tested, and upgraded independently.

The architecture also uses API-based communication between clients and
backend services. This approach allows the mobile and web applications to
share common business logic while supporting future integrations.

\subsection{Mobile Application -- Flutter}

Flutter is proposed for developing the mobile application for Android and
iOS.

The mobile application is designed primarily for photographers and community
users. It can provide functions such as:

\begin{itemize}
    \item searching and discovering Film Labs;
    \item viewing film processing services and prices;
    \item booking film processing services;
    \item tracking film processing and delivery status;
    \item receiving and accessing digital film scans;
    \item managing the Digital Film Archive;
    \item participating in the photography community and marketplace; and
    \item interacting with the AI Photography Assistant.
\end{itemize}

Using Flutter allows the project to develop a cross-platform mobile application
from a shared codebase.

\subsection{Web Portal -- ReactJS / Next.js}

ReactJS or Next.js is proposed for the web-based interface.

The web portal is mainly intended for Film Lab owners and administrators. It
can support Film Labs in managing their profiles, service packages, customer
orders, processing workflows, digital scan delivery, customer information,
and operational reports.

The web portal can also provide administration functions for managing users,
Film Labs, services, community content, and other platform resources.

\subsection{Backend Services -- ASP.NET Core Web API / Node.js}

ASP.NET Core Web API or Node.js with Express can be used to implement the
backend layer.

The backend is responsible for:

\begin{itemize}
    \item implementing business logic;
    \item receiving and processing requests from mobile and web applications;
    \item communicating with the PostgreSQL database;
    \item providing RESTful APIs;
    \item managing authentication and authorization;
    \item processing order and service workflows; and
    \item integrating external services such as AI, payment, logistics, and
    cloud storage.
\end{itemize}

This layer acts as the central connection between the client applications and
the platform's data and services.

\subsection{Database -- PostgreSQL}

PostgreSQL is proposed as the relational database management system.

The database stores structured information including:

\begin{itemize}
    \item user accounts and roles;
    \item photographer and Film Lab profiles;
    \item film processing services and service packages;
    \item orders and processing status;
    \item reviews and ratings;
    \item marketplace information; and
    \item other operational and community data.
\end{itemize}

A relational database is appropriate for maintaining relationships and
consistency among users, Film Labs, services, orders, and other business
entities.

\subsection{Authentication -- JWT and OAuth2}

JWT and OAuth2 are proposed to support secure authentication and authorization.

JWT can be used to maintain authenticated access to protected backend APIs.
After successful authentication, a token can be used to identify the user
when accessing authorized resources.

OAuth2 can support authentication through external identity providers when
required. Authentication can be combined with Role-Based Access Control
(RBAC) so that each user receives permissions according to their role.

\subsection{Cloud Storage -- Azure Blob Storage / Firebase Storage}

Azure Blob Storage or Firebase Storage can be used to store digital film
scans and other media resources.

Digital scans can be significantly larger than normal structured database
records. Therefore, storing these files in dedicated cloud storage can reduce
the burden on the relational database while providing scalable storage.

The storage layer should support secure access, backup, recovery, and future
growth of the Digital Film Archive.

\subsection{Artificial Intelligence Integration}

Artificial Intelligence is one of the main technologies that differentiates
the proposed platform from a basic Film Lab booking system.

The proposed AI components include:

\begin{itemize}
    \item \textbf{OpenAI GPT API:} provides conversational AI capabilities
    for the AI Photography Assistant.

    \item \textbf{LangChain or Semantic Kernel:} supports the development and
    orchestration of AI-powered workflows.

    \item \textbf{Retrieval-Augmented Generation (RAG):} allows the AI
    Assistant to retrieve domain-specific photography knowledge before
    generating an answer.

    \item \textbf{Recommendation Systems:} can recommend suitable Film Labs,
    film types, processing services, and learning resources according to
    user needs.

    \item \textbf{Computer Vision:} can be used as a proposed technology for
    analyzing the quality or characteristics of scanned film images.
\end{itemize}

These AI technologies support personalized assistance and intelligent
recommendation rather than replacing the core Film Lab processing workflow.

\subsection{Search Engine -- Elasticsearch / OpenSearch}

Elasticsearch or OpenSearch can be used to provide efficient search
capabilities.

The search engine can support:

\begin{itemize}
    \item Film Lab discovery;
    \item service and film-type searching;
    \item marketplace searching; and
    \item retrieval of photography-related knowledge and community content.
\end{itemize}

Search technology is especially useful when the number of Film Labs,
services, products, and knowledge resources increases.

\subsection{Cloud Deployment -- Microsoft Azure}

Microsoft Azure is proposed as the cloud deployment platform.

Azure can provide infrastructure for deploying backend services, databases,
cloud storage, and other components. Cloud deployment supports scalability
because computing and storage resources can be expanded as the number of
users, orders, and digital images grows.

\subsection{CI/CD -- GitHub Actions}

GitHub Actions can be used to support Continuous Integration and Continuous
Deployment (CI/CD).

The development workflow can automatically build and test project components
when changes are pushed to the repository. After successful validation, the
workflow can prepare or deploy updated components according to the project's
deployment configuration.

This reduces repetitive manual tasks and helps maintain consistency during
team development.

\subsection{Version Control and Collaboration -- GitHub}

GitHub is used as the version control and collaboration platform for the
project.

Team members can work on separate branches, record changes through commits,
review changes through pull requests, and merge completed work into the main
branch. This workflow is particularly useful for a multi-member software
engineering project because it allows different members to develop different
sections or components while maintaining a shared project history.

\subsection{Technology Integration}

The technologies above are integrated into a single platform architecture.

The Mobile Application and Web Portal communicate with the Backend Services
through RESTful APIs. The Backend communicates with PostgreSQL for structured
data and cloud storage for digital film scans. Search services support
efficient discovery of Film Labs and content. AI services provide
personalized assistance and recommendations. Azure provides cloud
deployment,
while GitHub and GitHub Actions support version control and CI/CD.

Together, these technologies provide the theoretical and practical foundation
for building a scalable digital ecosystem connecting photographers, Film Labs,
photography experts, delivery partners, administrators, and AI-powered
services.
