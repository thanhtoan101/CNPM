\section*{3.2.g Proposed Tasks}
\addcontentsline{toc}{section}{3.2.g Proposed Tasks}

To successfully develop the proposed AI-powered platform, the project will be divided into several major tasks. These tasks cover requirement analysis, system design, software development, AI research and implementation, testing, deployment, and final documentation.

\subsection{Task 1: Requirement Analysis and System Design}

The first task focuses on understanding the business requirements and defining the overall architecture of the platform.

Main activities include:

\begin{itemize}
    \item Conducting requirement analysis.
    \item Identifying stakeholders and system roles.
    \item Defining functional and non-functional requirements.
    \item Designing business processes and core user flows.
    \item Designing the overall system architecture.
    \item Developing database models and relationships.
    \item Defining backend service boundaries.
    \item Designing RESTful APIs.
\end{itemize}

The expected outcome of this task is a complete technical foundation that guides the implementation of the remaining components.

\subsection{Task 2: Mobile Application Development}

A Flutter-based mobile application will be developed for photographers and customers. The application will provide access to the major services of the platform through Android and iOS devices.

The development scope includes:

\begin{itemize}
    \item User authentication and profile management.
    \item Film Lab search and comparison.
    \item Service booking.
    \item Pickup and delivery requests.
    \item Real-time order tracking.
    \item Digital Film Archive access.
    \item Marketplace functions.
    \item Community interaction.
    \item AI Assistant integration.
\end{itemize}

The mobile application will communicate with backend services through secure APIs and provide a convenient user experience for photographers.

\subsection{Task 3: Web Portal Development}

Web-based systems will be developed for Film Lab owners and system administrators.

For Film Lab owners, the portal will support:

\begin{itemize}
    \item Service management.
    \item Pricing configuration.
    \item Order management.
    \item Workflow monitoring.
    \item Customer management.
    \item Digital scan delivery.
    \item Revenue reports and analytics.
\end{itemize}

For administrators, the system will support:

\begin{itemize}
    \item User management.
    \item Role and permission management.
    \item Film Lab approval.
    \item Marketplace management.
    \item Community content moderation.
    \item Payment and transaction monitoring.
    \item Complaint resolution.
    \item Overall platform monitoring.
\end{itemize}

\subsection{Task 4: AI Research and Implementation}

The project will investigate and implement Artificial Intelligence components that provide intelligent and personalized services.

The AI development tasks include:

\begin{itemize}
    \item Developing a Film Lab Recommendation Engine.
    \item Researching recommendation algorithms.
    \item Implementing semantic search.
    \item Developing a RAG-based Photography Assistant.
    \item Integrating Large Language Models.
    \item Building and managing a photography knowledge base.
    \item Researching Computer Vision techniques for scan quality analysis.
    \item Evaluating AI model performance.
\end{itemize}

Different AI approaches will be compared to identify suitable models that provide high recommendation accuracy, reliable image analysis, and effective conversational support.

\subsection{Task 5: System Integration and Testing}

After individual components are developed, the system will be integrated into a unified platform.

Main activities include:

\begin{itemize}
    \item Integrating mobile, web, backend, AI, and storage services.
    \item Performing functional testing.
    \item Performing API testing.
    \item Conducting integration testing.
    \item Performing security testing.
    \item Evaluating system performance.
    \item Identifying and resolving software defects.
    \item Optimizing system performance and scalability.
\end{itemize}

\subsection{Task 6: Deployment and Documentation}

The final task focuses on preparing the system for deployment and completing the required technical documentation.

Activities include:

\begin{itemize}
    \item Deploying services to cloud infrastructure.
    \item Configuring CI/CD pipelines.
    \item Configuring monitoring and backup mechanisms.
    \item Preparing technical documentation.
    \item Preparing user documentation.
    \item Documenting system architecture and APIs.
    \item Preparing the final Capstone report.
    \item Preparing presentation and demonstration materials.
\end{itemize}

\subsection{Expected Project Outcome}

Upon completion, the project is expected to deliver an integrated and scalable digital ecosystem for the analog photography community. The platform will connect photographers with Film Labs, support digital service management, provide marketplace and community functions, manage digital film archives, and integrate Artificial Intelligence for recommendation, semantic search, image analysis, and personalized photography assistance.
