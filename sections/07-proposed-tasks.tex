\section*{3.2.g Các nhiệm vụ đề xuất}
\addcontentsline{toc}{section}{3.2.g Các nhiệm vụ đề xuất}

To distribute the workload fairly, the project is organized into five
comparable work packages. Each member owns the analysis and design activities,
implementation or research, testing, and documentation associated with the
assigned package. The planned team capacity is allocated at approximately
20\% per member and will be monitored through sprint backlog items and story
points.

\subsection*{Gói công việc 1: Yêu cầu, kiến trúc và hệ thống phía máy chủ cốt lõi}

\textbf{Người phụ trách: Nguyễn Thái Gia Bảo}

\begin{itemize}
	\item Analyze stakeholder needs and system requirements; define use cases,
	acceptance criteria, business rules, and shared terminology.
	\item Design the modular system architecture, PostgreSQL data model,
	multi-tenant strategy, security model, and RESTful API conventions.
	\item Implement authentication, Role-Based Access Control, core domain
	services, database persistence, and integration contracts for storage,
	payment, and logistics providers.
	\item Prepare architecture diagrams, the entity-relationship diagram, API
	documentation, unit tests, and backend integration tests.
\end{itemize}

The expected outputs are the requirements baseline, architecture and database
designs, API specification, core backend services, and backend test evidence.

\subsection*{Gói công việc 2: Ứng dụng di động dành cho nhiếp ảnh gia}

\textbf{Người phụ trách: Huỳnh Gia Hợp}

\begin{itemize}
	\item Design and implement the Flutter application for Android and iOS.
	\item Implement Film Lab discovery and comparison, service booking, pickup
	and delivery requests, online payment, order tracking, and notifications.
	\item Integrate the Digital Film Archive, Marketplace, community features,
	and AI-powered Photography Assistant into the mobile experience.
	\item Perform mobile usability, functional, API integration, and error-state
	testing; document the user flows and implementation decisions.
\end{itemize}

The expected outputs are the mobile application, reusable user-interface
components, API integrations, mobile user-flow documentation, and test results.

\subsection*{Gói công việc 3: Cổng thông tin web dành cho cơ sở xử lý phim và quản trị hệ thống}

\textbf{Người phụ trách: Nguyễn Đào Quốc Khánh}

\begin{itemize}
	\item Develop responsive ReactJS or Next.js portals for Film Lab operators
	and System Administrators.
	\item Implement Film Lab profiles, service packages, pricing, order intake,
	processing-stage management, scan uploads, customer management, revenue
	reports, and operational dashboards.
	\item Implement user and Film Lab administration, service categories,
	transaction fees, payment monitoring, Marketplace and content moderation,
	complaint handling, and dispute resolution.
	\item Perform web usability, functional, authorization, and API integration
	testing; document administrative and laboratory workflows.
\end{itemize}

The expected outputs are the Film Lab portal, administration portal, responsive
interfaces, workflow documentation, and web test evidence.

\subsection*{Gói công việc 4: Các thành phần AI và học tập dựa trên nghiên cứu}

\textbf{Người phụ trách: Lê Thị Như Quân}

\begin{itemize}
	\item Prepare representative datasets, domain knowledge, baselines, and
	evaluation protocols for the AI experiments.
	\item Design and compare approaches for Film Lab and film-stock
	recommendation, semantic search, the RAG-based Photography Assistant, and
	Computer Vision-based scan-quality analysis.
	\item Expose the selected models through documented service APIs and
	integrate them with the shared backend contracts.
	\item Report datasets, metrics, experimental results, limitations, and
	responsible-use considerations for each AI component.
\end{itemize}

The expected outputs are AI service prototypes, a curated knowledge base, model
APIs, reproducible experiment configurations, evaluation results, and the
Research-Based Learning documentation.

\subsection*{Gói công việc 5: Tích hợp, bảo đảm chất lượng và bàn giao}

\textbf{Người phụ trách: Nguyễn Thành Toàn}

\begin{itemize}
	\item Coordinate API contracts and integrate the mobile, web, backend, AI,
	storage, search, payment, and logistics components into a unified MVP.
	\item Define end-to-end scenarios and coordinate functional, integration,
	security, recovery, and performance testing; track defects to closure with
	the responsible module owners.
	\item Configure GitHub Actions, cloud environments, deployment procedures,
	logging, monitoring, backup, and recovery verification.
	\item Consolidate technical evidence, terminology, cross-references, test
	results, the final Capstone report, presentation slides, and the product
	demonstration package.
\end{itemize}

The expected outputs are the integrated and deployed MVP, CI/CD pipeline,
system-level test report, deployment and operations guide, consolidated report,
presentation, and demonstration package.

\subsection*{Trách nhiệm chung và kiểm soát khối lượng công việc}

All members participate in sprint planning, peer review, integration testing,
issue resolution, and the final demonstration. Each member remains responsible
for correcting defects and supplying documentation for the owned component.
Toàn coordinates system-level integration and report consolidation but does not
replace the technical ownership of the other members. Backlog estimates and
actual effort will be reviewed at the end of each sprint; work will be
redistributed when a package materially exceeds its planned 20\% share.

\subsection*{Trình tự triển khai}

\begin{enumerate}
	\item \textbf{Yêu cầu và kiến trúc:} establish the requirements
	baseline, architecture, data model, API contracts, and acceptance criteria.
	\item \textbf{Phát triển và nghiên cứu song song:} implement the backend,
	mobile application, web portals, and AI prototypes against the agreed
	contracts.
	\item \textbf{Tích hợp tăng dần:} connect completed components early,
	validate core business flows, and resolve contract mismatches.
	\item \textbf{Kiểm thử hệ thống và đánh giá AI:} execute end-to-end quality
	assurance while evaluating AI accuracy, retrieval quality, groundedness, and
	scan-analysis performance.
	\item \textbf{Triển khai và hoàn thiện:} deploy the MVP, verify operations,
	complete the documentation, and prepare the final report, presentation, and
	demonstration.
\end{enumerate}

\subsection*{Tích hợp tổng thể dự án}

The deliverables collectively form a unified ecosystem for analog photography.
The mobile application is the primary customer interface, while the Film Lab
and administration portals support service operations and platform governance.
Backend services, cloud storage, search, and the Digital Film Archive provide a
shared technical foundation. The Marketplace and knowledge-sharing modules
support sustainable community engagement, and the AI layer enhances the
ecosystem through personalized recommendations, semantic retrieval, contextual
assistance, and scan-quality analysis.

The five work packages directly correspond to the functional requirements,
non-functional requirements, research objectives, and expected products. Clear
ownership makes progress measurable, while the shared review, integration,
testing, and documentation responsibilities preserve collective accountability
for the final system.
